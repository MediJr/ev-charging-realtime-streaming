# Sources LaTeX des rapports · LaTeX report sources

| Fichier · File | Contenu · Content |
|---|---|
| `report-style.sty` | Mise en page commune (polices, couleurs, page de titre, encadrés) · Shared layout |
| `rapport-fr.tex` | Rapport en français · French report |
| `report-en.tex` | Rapport en anglais · English report |

Les graphiques proviennent de `../livraison/figures/{fr,en}/`, générés par le pipeline (`docker compose run --rm --no-deps -v ./docs:/app/docs --env-from-file .env simulator python -m lumio_stream.report …`).
Charts come from `../livraison/figures/{fr,en}/`, generated by the pipeline.

## Compilation · Build

Prérequis : une distribution LaTeX avec **XeLaTeX** (MiKTeX ou TeX Live) et les polices TeX Gyre.
Requirements: a LaTeX distribution with **XeLaTeX** (MiKTeX or TeX Live) and the TeX Gyre fonts.

```bash
cd docs/rapport
latexmk -xelatex -outdir=build rapport-fr.tex
latexmk -xelatex -outdir=build report-en.tex
```

Les PDF publiés sont copiés dans `docs/livraison/` · Published PDFs are copied to `docs/livraison/`.
